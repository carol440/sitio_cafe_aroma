# Sitio Café Aroma
Proyecto del taller de Git - Cafetería.

## Descripción
Sitio web estático para la cafetería Café Aroma con secciones de menú, contacto y más.

## Instalación
Para instalar, descarga el ZIP del repositorio y descomprímelo en tu carpeta de proyectos. Luego ejecuta el sitio con Live Server desde VS Code.
