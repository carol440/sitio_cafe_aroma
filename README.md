# Sitio Café Aroma
Proyecto del taller de Git - Cafetería.

## Descripción
Sitio web estático para la cafetería Café Aroma con secciones de menú, contacto y más.

## Instalación
1. Clona este repositorio: git clone https://github.com/carol440/sitio_cafe_aroma.git
2. O descarga el ZIP y descomprímelo en tu carpeta de proyectos
3. Abre index.html en tu navegador o usa Live Server en VS Code
4. Disfruta del mejor café
